\# AI NFT Image Generator



Android application that generates NFT-style artwork using AI image generation APIs.



\## Features

\- AI image generation from prompts

\- Download generated images

\- Share generated images

\- Modern Android UI

\- Fast API integration



\## Technologies Used

\- Java

\- Android Studio

\- Retrofit

\- REST APIs

\- JSON Parsing

\- AI Image APIs



\## Project Structure

\- Android frontend

\- API integration

\- Image rendering system



\## Future Improvements

\- User authentication

\- NFT marketplace integration

\- Cloud image storage
